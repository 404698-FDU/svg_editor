# SVG 编辑器（CLI 版）— 阶段一说明文档

> 复旦大学 `CS30075.01 软件设计` 课程项目 Phase 1

## 1. 环境与运行方式

- **Node.js**: >= 18
- **安装依赖**:
  ```bash
  npm install
  ```
- **启动交互式 CLI**:
  ```bash
  npm start
  # 或指定初始加载的 SVG 文件：
  npm start -- path/to/file.svg
  ```
- **编译 TypeScript**:
  ```bash
  npm run build
  ```
